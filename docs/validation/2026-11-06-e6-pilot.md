# E6 pilot: when does one agent with many cursors pay off? (2026-11-06)

A pilot, not a result: 6 windows per run, one run per cell, four conditions running at once on one Mac (so times are only indicative). Its job was to calibrate the tunable workload and the new arms before a preregistered experiment.

## Setup

- **Workload** (`lab/workloads/tunable`): a 12-page purchase-request wizard per window, local only (local server, local headless Chrome). Each page is either identical on every window or differs in one controlled way:
  - **look:** layout and language;
  - **timing:** a notice at a different moment;
  - **judgement:** a fact that changes the answer, or a pre-filled value that may be stale;
  - **path:** two extra pages on about half the windows.
- **Knobs:** the share of identical pages (100/75/50/25/0%, with all four kinds of difference mixed), and each kind alone at 50%.
- **Arms:**
  - **P-T:** one agent per window;
  - **F:** one agent drives every window;
  - **D:** a director broadcasts and hands diverging windows to helper agents running in parallel;
  - **DA:** D, plus automatic handoff after 2 failed broadcasts;
  - **S:** AI writes a script.
- **Model and grading:** `gpt-6-astra` (medium). Grading reads the submitted requests.

## What the pilot showed

1. **The task is too easy to separate the arms on correctness.** Almost every cell is 6/6. The main experiment needs more windows (24+) and harder pages.
2. **F is cheaper than one agent per window but slower.** It used 40–60% fewer tokens and took 2–3× the time, because it works through the windows in turns.
3. **D handed off almost everything.** Even at 75% identical pages it gave 5 of 6 windows to helpers, so it cost about as much as one agent per window. With timing differences only, it handed off none and was the cheapest agent arm. The prompt was tightened afterwards (commit `c4614f6`), so that D hands off only windows that need their own decisions. When to hand off is the key ablation for the main experiment.
4. **AI-written scripts are cheapest but fail on judgement.** At 50% and 25% identical pages, S submitted wrong requests on 6/6 and 3/6 windows. Wrong records are worse than unfinished ones.
5. **Real Odoo (E5) agrees.** With identical companies, F matched one agent per company at 2.5% of the tokens. Once versions and languages differed, one agent driving all 48 windows fell apart: 0/48 at L1 and 25/48 at L2.

## Limits

- n = 6 windows and one run per cell; no variance estimate.
- Four conditions ran at once, so wall times include contention.
- `share50-path` F and `share50-judgement` F and D ended with 5/6.
