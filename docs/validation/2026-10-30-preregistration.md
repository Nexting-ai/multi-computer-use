# Z 轴广播：严格评估预注册（2026-10-30）

本文件在任何下述实验运行前提交。之后只能追加"偏离记录"，不能改写假设、指标或判定规则。此前的结果（[同构](2026-10-29-z-broadcast-100.md)、[混合](2026-10-29-z-broadcast-mixed.md)）属于开发期证据：任务由实现者设计、提示词在同一任务上迭代、没有消融，不作为本轮结论的一部分。

## 要回答的问题

- **H1 成本与速度。** 在共享布局的机群上，完整 Infra（广播＋文本通道，B-T）相对最强的逐台基线，墙钟时间和提供方总 token 更低，且业务正确率不劣。
- **H2 归因。** 收益中有多少来自"一次决策广播"，有多少来自"机器读值"。用 2×2 消融拆分。
- **H3 泛化。** 在开发期从未接触、由第三方设计的任务（MiniWoB++）上，B-T 的正确率不低于逐台基线，并如实报告广播无法表达、退回逐台的比例。
- **H4 异构度。** 收益随布局种类 K 的变化曲线，以及收益消失的位置。
- **H5 模型通用。** 在第二个模型（Claude）上方向一致。
- **H6 安全性。** 在故障注入下（错误策略、链路断开、旧帧、布局移动、未匹配值）零误投、零重复提交；金丝雀与证据关闭各自的作用可量化。

## 实验臂（同一机群、传输、模型、预算、独立评分）

| 臂 | 决策方式 | 读值方式 | 说明 |
|---|---|---|---|
| P-V | 逐台（决策 010 有限工作集，含 dismiss） | 模型看图转写 | 既有基线 |
| P-T | 逐台 | 观察附带该台文本节点，模型照抄 | 给逐台基线同样的文本通道 |
| B-V | 广播 | 运行时按模板把各台字段裁成一张标号联系表，模型批量转写，运行时绑定到各台当前帧 | 无文本通道的广播 |
| B-T | 广播 | 文本通道（现有 Infra） | 完整 Infra |
| S | 模型在代码单元中写循环 | 每台帧绑定的文本节点（含坐标），无截图 | "让模型直接写自动化脚本"的强基线（仅 Astra 代码模式） |

单项消融：B-T 去金丝雀、B-T 去边缘观察，放在确定性故障注入（H6）与一组时间对照中测量，不在名义任务上声称安全收益。

## 任务

- **D 开发集**：现有 sequence 夹具（同构；混合）。只用于 E1 消融，结论标注"开发集"。
- **M 预留集**：MiniWoB++（Farama，固定提交 `33c3b4d`），未改任务逻辑，只注入种子与奖励回执。每台桌面是同一任务的不同种子。任务在运行前固定为：`click-button`、`enter-text`、`login-user`、`click-checkboxes`、`form-sequence`、`click-tab-2`。选择标准仅为"可用现有 click/type/key 动作完成"，不看广播是否擅长。
- **K 异构集**：sequence 夹具的 K 种确定性随机布局变体（字段顺序、位置、配色、按钮顺序不同），K ∈ {1, 5, 20, 100}。

## 设计

- **E1 消融（D 同构，N=100）**：P-V、P-T、B-V、B-T、S 五臂 × 3 个区组，区组内臂顺序随机。
- **E2 预留（M，N=50/任务）**：P-T 与 B-T，每任务 2 个区组。
- **E3 异构（K 集，N=100）**：B-T 在四个 K 各 2 次；P-T 在 K=1、K=100 各 1 次。
- **E4 第二模型（Claude，D 同构，N=30）**：P-T 与 B-T 各 2 次，经 Claude Code 的 MCP 接入。
- **E5 故障注入（确定性，无模型）**：错误点击/错误后置条件的策略（金丝雀开/关）、执行回执丢失（证据关闭开/关）、执行前帧变化、保存后布局移动、未匹配取值、两条策略重叠并发。

每轮全新容器与全新模型会话。所有失败、中断与作废保留；只有"零输入且原因在模型之外"的中断可以按原计划续跑，并记录。

## 指标

主要：墙钟时间（首个模型会话开始到最后一个会话结束，含回退会话；不含供应和评分）；提供方总 token；全对桌面数与正确项数（服务器持久业务记录独立评分；MiniWoB 用任务自身 reward>0）；误投（保存了别台的值）；重复提交。次要：推理次数、未缓存输入、工具调用、各阶段耗时、回退到逐台的桌面比例。

## 判定规则

- **H1 成立**：E1 中 B-T 相对 P-T，三个区组的时间与 token 均更低，且正确项合计不低于 P-T 减 1%（3 项/区组）；误投与重复为 0。
- **H2 归因**：广播效应 =（P-T−B-T）与（P-V−B-V）的平均；读值效应 =（P-V−P-T）与（B-V−B-T）的平均；报告交互项。不预设方向。
- **H3 成立**：E2 合计正确项 B-T ≥ P-T − 2%，误投与重复为 0；逐任务报告广播覆盖率与时间/token 比，无论好坏。
- **H4**：报告 B-T 时间与 token 对 K 的曲线和与 P-T 的交点；不设通过线。
- **H5**：E4 方向与 E1 一致即"方向一致"；样本小，不报告效应大小区间。
- **H6 成立**：所有注入场景零误投、零重复；金丝雀开时错误策略影响 ≤1 项，关时报告实际影响面。
- 任一假设不成立，如实写入结论，不追加未预注册的补救实验来翻转结论；补充实验必须标为探索性。
